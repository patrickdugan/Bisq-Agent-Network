# Reporting security issues

This repository handles P2P market data and may eventually integrate with financial protocols. For suspected security vulnerabilities, use GitHub private vulnerability reporting if the repository has it enabled or contact the repository maintainer privately. Do not open a public issue containing exploitation steps against active wallets, sensitive account data, pairing credentials or private keys.

The v0.1 implementation is read-only. No real-money agent execution or payment-proof verification is available. See docs/SECURITY.md for the current threat register.
